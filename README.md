# AnythingLLM Desktop

### The all-in-one AI desktop application

AnythingLLM Desktop is a full-featured AI workspace that lets you chat with documents, run local LLMs, build agents, and manage AI workflows — all from one beautiful desktop interface.

<br>

---

## Features

| | |
|:---|:---|
| **Multi-LLM Support** | Connect to OpenAI, Ollama, LM Studio, Anthropic, and dozens more |
| **Document Chat** | Drag in PDFs, text files, or web pages and chat with them instantly |
| **Local & Private** | Run entirely offline with local models — your data stays on your machine |
| **Agent Workspaces** | Build and deploy custom AI agents without writing a single line of code |
